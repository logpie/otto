## Anomalies / follow-ups

1. **`--yes` flag rejected by i2p path**: stderr says `i2p mode: these
   flags are ignored — pass them to 'otto run' if needed: --yes`. But
   `otto run` is not a documented subcommand (per
   `reference_otto_cli.md`). Either the message is stale or `--yes`
   should be silently accepted in i2p.
2. **`--budget` semantics**: code expects wall-clock seconds (used
   1200), not USD. The brief said `--budget 10` for "$10 cap" — would
   have been a 10-second cap (instant timeout). Worth a docstring
   note.
3. **Missing `summary.json`**: per CLAUDE.md the session root should
   contain `summary.json` with `cost_usd / wall_s / verdict / status`.
   In this i2p run only `proof-packet.{html,json}` and
   `spec-state.jsonl` exist at session root. Either the doc is stale
   or the writer dropped during the redesign.
4. **Real merge bug**: `home-counter` slice didn't persist its files
   to the integrated repo. Worth a separate investigation of the
   merge-queue's commit/sync step — but out of scope for this smoke.
